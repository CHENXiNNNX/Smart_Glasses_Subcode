1. AI流程
- 检测是否联网 → 未联网则进入配网模式(暂留空实现，先只给日志提示没联网) → 成功联网后则进入设备激活检测
- 设备未激活则等待激活 → 激活成功后则进入待机状态
- 待机状态 → 等待唤醒词
- 检测到唤醒词 → 我这边默认发送“唤醒词到ai服务器识别”并得到ai回复
- ai回复后 → 进入监听 → STT → LLM → TTS
- TTS结束 → 继续监听 → 如果持续没有数据进行ai对话的话等待5分钟后回到待机状态（等待下次唤醒词唤醒）

2. 状态机

    LISTENING,          // 监听中
